# MINECRAFT? 0.2.0 검증 기록

## 변경과 배포본

- 인벤토리 기본 크기 150%, Settings → Inventory size 75~225% 슬라이더, 즉시 반영·저장·초기화. 웹사이트 배율과 별도입니다.
- 동일한 탭 상태는 다시 적용하지 않고, 플레이어 텍스처 면을 재사용합니다. 숨긴 플레이어와 바뀌지 않은 프레임의 그리기를 건너뜁니다.
- Settings → Import from Chrome에서 암호 CSV와 사용자 실행 Chrome 도우미의 쿠키·북마크를 가져옵니다. [사용 안내](CHROME-IMPORT.md).
- `release/Minecraft-Browser-Setup-0.2.0-x64.exe`, Windows x64 NSIS, 168,789,017 bytes. 전자서명은 없습니다.
- SHA-256: `6e023ec1c7a31f2f096ae4fe10910e431b34e60caa5f8c732a624196e098e45c`.
- 실행 환경: Electron 44.9.0 / Chromium 152.0.7977.167. 사용자 설치본을 덮어쓰지 않고 새 패키지의 `win-unpacked`를 격리 프로필로 실행했습니다. 설치 마법사를 통한 실제 업그레이드는 이번 검사에 포함하지 않았습니다.

## 성능 측정 범위

동일 환경에서 같은 탭 상태 통지 50회와 마우스 이동 60회를 실행했습니다. 변경 전 자료는 `design/evidence/v12/performance-before/result.json`, 최종 패키지 측정은 `release-performance/result.json`입니다.

| 측정 | 변경 전 | 최종 패키지 |
| --- | ---: | ---: |
| 동일 상태 통지 중 탭 목록 DOM 변경 | 100 | 0 |
| 동일 상태 통지 중 임시 캔버스 생성 | 3,600 | 0 |
| 동일 상태 통지 중 drawImage 호출 | 7,400 | 0 |
| 마우스 추적 중 임시 캔버스 생성 | 7,344 | 2 |
| 마우스 추적 중 drawImage 호출 | 15,096 | 5,114 |

짧은 이 측정의 CPU 샘플도 감소했으나 전체 브라우저·외부 사이트의 CPU/메모리나 체감 FPS를 입증한 것은 아닙니다. 웹사이트의 자체 부하, 장시간 사용, 다양한 GPU·디스플레이 환경은 별도 관찰이 필요합니다.

## 아직 확인하지 않은 범위

사용자의 실제 Chrome 계정/암호/쿠키는 읽거나 이전하지 않았습니다. Chrome에 도우미를 직접 로드한 실제 계정의 전체 이전은 미검증입니다. 개발 검사에는 합성 데이터와 실제 Windows 암호화·브라우저 쿠키 세션을 사용했습니다. 파티션 쿠키·기기 바인딩 키·패스키·카드·방문 기록·확장 프로그램은 이전 대상이 아닙니다. 일부 사이트는 재로그인이 필요합니다.

Google/Gmail 로그인·실제 메일 도착, YouTube 광고 차단·재생, DRM, 모든 사이트의 로그인 양식과 세션 유지, 실제 설치 마법사를 통한 기존 사용자 프로필 업그레이드는 이번 검사로 보장하지 않습니다. 기존 설치본/프로필과 개발 시안 서버는 변경하지 않았습니다.

증거와 캡처는 `design/evidence/v12/`의 각 `result.json`과 PNG에 보존합니다.
