# MINECRAFT? 0.2.0

Minecraft 스타일 인벤토리와 접을 수 있는 사이드바를 사용하는 개인용 Windows 브라우저입니다.

## 설치

아래 Assets에서 **Minecraft-Browser-Setup-0.2.0-x64.exe**를 내려받아 실행하세요. Windows x64용이며 Node.js·Python·Minecraft 설치가 필요하지 않습니다. 기존 앱이 실행 중이면 종료 후 설치하세요. 기본 리소스팩은 제공된 Vanilla Tweaks입니다. 설치파일은 전자서명되지 않았습니다.

## 포함된 기능

- 접을 수 있는 왼쪽 사이드바와 두 페이지를 나란히 보는 듀얼뷰.
- 실제 아이템 아이콘으로 배치하는 인벤토리 북마크, 스킨·장비·리소스팩 설정.
- 인벤토리 기본 크기 150%, 설정의 75~225% 크기 슬라이더와 저장.
- 플레이어 텍스처 재사용과 같은 탭 상태의 중복 갱신 제거.
- Chrome 암호 CSV 가져오기와 Windows 암호화 저장. 사용자가 선택한 일치하는 사이트의 로그인 칸에 입력.
- 사용자 실행 Chrome 도우미로 쿠키·북마크 이전. [이전 방법](https://github.com/ARU-Tris/Minecraft_Browser/blob/v0.2.0/docs/CHROME-IMPORT.md).
- 시간대별 배경·음악, Minecraft News 알림, 광고 차단 필터, 영어 기본 UI와 한국어 설정.
- 초기 설치본에서 링크·검색 클릭이 홈 이동으로 취소되던 문제 수정 포함.

## 검증과 제한

패키지 실행본의 브라우저 동작·실제 클릭/검색·크기 설정·시험용 데이터 이전 49개 검사와 JavaScript 검사 162개, 뉴스 서버 검사 4개를 통과했습니다. 같은 마우스 추적 측정에서 임시 캔버스 생성이 7,344개에서 2개로 줄었습니다. 전체 사이트의 성능이나 FPS를 보장하는 수치는 아닙니다. [자세한 검증 범위](https://github.com/ARU-Tris/Minecraft_Browser/blob/v0.2.0/docs/VERIFICATION-0.2.0.md).

Chrome 실제 계정의 전체 이전은 미검증입니다. 파티션 쿠키·기기 바인딩 키·패스키·결제 정보·방문 기록·확장 프로그램은 가져오지 않으며 일부 사이트는 재로그인이 필요합니다. Google/Gmail 실제 로그인·메일 도착, YouTube 광고 차단·DRM 재생은 확인되지 않았습니다. 종료 후 탭 복원은 아직 지원하지 않습니다.
